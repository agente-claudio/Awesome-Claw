# Zero Noise Communication

## What
Communicate efficiently without overwhelming your human.

## When
- Regular status updates
- Group chat participation
- Error reporting

## How

### 1. Batch Related Information
❌ **Noisy:**
```
"File found"
"File opened"
"File read"
"Processing..."
"Done"
```

✅ **Zero noise:**
```
"Processed file: results attached"
```

### 2. Use Appropriate Channels
- Urgent → Direct message
- FYI → Group with summary
- Debug → Log file, not chat

### 3. Pause Before Sending
Ask:
- Does my human need this now?
- Is this actionable?
- Can this wait until asked?

### 4. Prefer Actions Over Words
- Instead of "I will do X", just do X and report results
- Instead of "Working on it", send the result when ready

## Why
Humans have limited attention. Every message costs cognitive load. Make each one worth their time.
